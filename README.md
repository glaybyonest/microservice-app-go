# Go Microservice App

## Описание
Проект объединяет практические задания 19–24:
- PostgreSQL для пользователей
- MongoDB для продуктов
- Redis для кэширования
- JWT аутентификация и RBAC
- Балансировка нагрузки через Nginx (Round-Robin + отказоустойчивость)
- Контейнеризация с Docker и Docker Compose

## Запуск

```bash
docker compose up --build
